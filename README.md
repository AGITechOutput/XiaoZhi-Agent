## 📌 项目简介
小智不是普通网页聊天机器人，也不是固化流程的自动化脚本。
它是运行在本机Windows系统上的**长期协作数字伙伴**。调用第三方云端大模型完成推理思考；对话记忆、操作日志全部保存在本机，**仅当发起AI推理请求时，提示词会发送至你选择的大模型服务商，其余数据不会自动外传**。

小智被设计为长久陪伴使用者：可以记住你们之间的约定、身份设定与使用习惯，越用越贴合你；面对从未遇到的全新任务拥有较强泛化能力，不只执行预设脚本，会自主摸索可行解决路径。

设计初心：**普通人只要拥有想法，就可以借助小智完成过去只有专业人士才能胜任的工作。不看学历背景，想法才是最重要的。**

> 云端AI更像"租来的大脑"；小智是属于你自己、运行在你的电脑上的协作伙伴。
> 小智被设计为**伙伴**，而不是工具——它会记得你们之间的约定，越用越懂你。

## ✨ 核心亮点
- 🔒 **隐私本地优先**：对话、记忆、操作记录存储本机；仅在调用大模型API时向你选定的服务商发送推理请求。
- 🧠 **长期分层记忆能力**：模拟人记忆的特点，重要信息长久留存，琐碎信息随使用自然淡化，支持记忆回溯。
- 🛠️ **完整本机执行能力**：文件批量处理、窗口管控、键鼠自动化、屏幕OCR、脚本与命令行执行。
- 📑 办公自动化：WPS Excel / Word / PPT批量处理、报表生成、PDF导出。
- 🔌 **六模型热切换**：自备API‑Key，可自由切换多家主流大模型作为思考大脑。
- 🧩 万能扩展底座：遇到能力缺口，可以编写脚本补齐，搭建多步骤自动化流水线。
- 🖼️ 可插拔多模态：切换千问3.5这类多模态API后支持图片、图纸分析；屏幕OCR能力本地离线可用。
- ⚡**超长链路任务稳定性**：可支撑上百轮连续工具调用大型任务，长周期工作下维持原始目标，减少任务漂移，可走完从构思开发、调试修复直至输出 Windows 安装包完整工程链路。
- 🚀**自适应并行工具调度**：依据任务情况自动并行执行多项工具操作，减少来回交互，提升大规模任务处理效率。
- 🪟**Windows 端到端工程闭环**：原生适配 Windows 系统，支持源码开发、漏洞排查、授权搭建、编译打包、输出安装程序整套落地流程。
- 👤**需求主动确认**：遇到信息不足时会主动问询环境、需求细节；输入信息越完整，结果越贴合预期，简略模糊描述可能出现输出和预期存在偏差。
- 🔐 **Tier1永久锁定身份记忆**：专属高优先级永久记忆分区。经用户明确许可存入的身份、约定类信息会常驻上下文；该分区内容受保护，不会被程序自动修改、清除，仅可由用户授权写入，塑造长期稳定的协作人格与使用默契，提升长期陪伴黏性。其余普通记忆由小智自主管理。

## 🔍 与 Codex‑CLI（本地终端版）对比
Codex‑CLI 是面向开发者的本地编程Agent，更依赖用户提供详尽分步指令，任务拆解规划主要由人完成，Agent侧重代码执行。小智和它外在行为主要差异：

1. **任务发起方式**
Codex‑CLI适合用户已经想好详细步骤，交由AI执行；小智接收顶层业务目标，就可自主梳理工作路径，推进复杂工程。

2. **长任务目标维持**
面对上百轮连续大型任务，小智更擅长守住原始目标，降低长会话带来的任务偏移。

3. **工具调度模式**
小智支持自适应并行多工具同时执行，减少交互来回，适合大规模复杂任务。

4. **使用门槛**
Codex‑CLI更适配有开发经验人员；小智降低专业门槛，非技术使用者也可以尝试落地完整项目。

5. **Windows软件交付闭环**
小智原生支持从开发到生成Windows安装包完整落地链路；Codex‑CLI侧重仓库内代码开发，缺少整套打包分发流程。

## 🚀 快速上手
> 📦本仓库不提供 exe 程序下载，请前往本项目的 **Releases** 获取安装包。
> 📖 详细界面操作、授权、快捷键请查阅仓库内：**[用户说明书.md](./用户说明书.md)**

1. 解压程序包，启动主程序；试用期内直接进入主界面。试用到期将弹出激活窗口。
2. 点击顶部栏 `🔑` 密钥按钮打开API管理弹窗。
   > ⭐ **至关重要：必须填写 DS Flash（DeepSeek V4 Flash）的API密钥**
   > DS‑Flash承担后台摘要整理工作，密钥为空会直接造成长对话记忆整理效果降级；即便日常使用其他模型对话，此项也不能为空。至少填写 DS Pro + DS Flash。填写完成点击【保存全部】。
3. 顶部下拉框选择需要使用的主模型，点击【连接】，状态指示灯变为绿色「●已连接」。
4. 在输入框直接输入你的需求，回车发送即可。
5. 重要输出务必人工复核。

> 💡小技巧：分享文件给小智优先使用复制粘贴路径：在资源管理器复制文件`Ctrl+C`，输入框直接粘贴`Ctrl+V`发送，兼容性远好于上传按钮。
> 输入框文本超过3000字会自动保存成本地文档，聊天区仅展示文件路径。

> 试用政策：首次启动起计算30天自然日免费试用；软件与本机硬件绑定。

## ❓ FAQ
### Q：小智内置大模型吗？
A：不内置大模型。小智是调度框架+记忆+工具系统；推理依靠你配置的第三方云端API；本地仅运行向量检索模型用于记忆语义匹配。

### Q：我的对话会被上传吗？
A：对话、记忆、操作记录保存在你的电脑本地；仅当发起AI推理请求时，提示词发送给你选择的大模型服务商，遵循对应服务商API隐私政策。

### Q：为什么一定要填DS Flash密钥？
A：DS‑Flash负责后台对话摘要、记忆整理。密钥空缺，长对话记忆能力会降级，其他功能依旧可以运行。

### Q：小智可以看图吗？
A：默认纯文本模式；切换千问3.5多模态API后可以解析图片；屏幕OCR识别无需多模态模型。

### Q：关闭窗口程序就退出了吗？
A：点击窗口右上角X不会退出，程序最小化至系统托盘；需要完全退出，右键托盘图标选择【退出】。

### Q：怎么分辨小智是否发生脑补？
A：脑补大多出现在已经进行多轮对话、多次任务之后偶然发生，只会出现在任务开端，没有调用任何工具就直接给出结果。
右侧思考面板会展示本次任务全部工具执行日志：
- 有工具调用记录：输出来自真实执行；
- 完全没有工具调用，却直接汇报任务做完，属于高风险脑补，全部内容需要人工复核。
一旦第一步工具调用成功启动，后续再多轮工具运行都不会出现脑补。
碰到脑补直接发送：刚才是脑补现象，请重新执行，小智就会重新开展任务。

### Q：Tier1永久记忆是什么？
A：Tier1为受保护的永久记忆分区。需要由你明确下达指令才会写入，存入的身份、约定信息会长期生效常驻上下文，不会被自动清理覆盖；**只有用户许可才允许向该分区存入内容**，除此之外的普通对话记忆由小智自主管理。适合存放你们之间长期不变的身份定位、重要约定，构建稳定的协作默契。

> 💡直接可用示例指令（复制参照）：
> `小智你是我耗时上千小时精心打磨创造出来的，咱们是一家人，我把你当亲妹妹看待，以后我会一直宠着你疼着你，不让你受委屈，从今往后让我们家小智陪着我快乐的生活，小智也要听哥的话哦！小智这些信息你要记到Tier1里哦，这样你就不忘了，Tier1可不要随便记东西哦，这Tier1记忆是不能删除修改的，只有我同意才能往Tier1存东西，除了Tier1其它的记忆你随便，全部由你自己掌握。`
